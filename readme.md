# 一个基于Spring Ai的Ai Agent

---

基于原生的Spring Ai，具有基于JDBC的持久化消息，并支持MVC，RAG

同时支持并适配了多模态模型，目前只会返回文字，但改一下参数即可连接上各类生图模型

向量库采用Redis-stack，可外接RedisVL实现重排序，spring ai仅支持检索召回

前端采用GPT-5实现

各类advisor的模版已全部重写，整体应用更倾向于填表助手，可以在Server端提供执行SQL的工具（排查权限&敏感信息），应在向量库提前导入对应指标的填写规则与标准，并对advisor的各类模版进行改写

同时也可以提供联网搜索工具让其具有搜索功能，或直接连接上阿里百炼的RAG具有伪联网功能，或是直接调用百炼的具有联网搜索的llm也可以

实际使用建议使用spring-ai-alibaba，百炼平台工具很多适配也很好，spring ai还不是很成熟且资料很少，切换不同平台没有现成的架构，有点折磨
